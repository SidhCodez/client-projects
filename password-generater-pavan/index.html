About vault

A private, local-first password manager.

How to run

1. Save index.html anywhere on your computer.
2. Double-click it, or open it in any modern browser.
3. No server, no install, no internet required after first load.
4. Your data lives in localStorage — only accessible by this browser on this device.

⚠ Security note
Passwords are stored in plain text in your browser's localStorage. This is fine for personal, low-risk use on a device only you control. Do not use this on a shared or public computer. For high-security needs, use a dedicated password manager like Bitwarden (open-source) or 1Password.
Optional enhancements

• AES-256 encryption (using Web Crypto API) with a master password
• Import / export vault as an encrypted JSON file
• Password history per entry
• TOTP / 2FA code storage
• Auto-lock after inactivity timeout
• Browser extension for auto-fill
• Offline PWA (installable, works without network)
